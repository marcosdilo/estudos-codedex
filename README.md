# 👾 Meus Estudos no Codédex

Bem-vindo ao meu repositório de estudos! Aqui documento meu progresso, exercícios e projetos práticos desenvolvidos na plataforma [Codédex](https://www.codedex.io/). 

O objetivo principal deste repositório é manter um registro da minha jornada de aprendizado em desenvolvimento de software, praticar o versionamento de código e armazenar consultas rápidas para o futuro.

## 🚀 Tecnologias e Linguagens

Durante as trilhas do Codédex, os estudos focam na construção de uma base sólida nas seguintes tecnologias:

*   **Python**
*   **HTML & CSS**
*   **JavaScript**
